# ArianElements

یک کتابخانه کامپوننت React با پشتیبانی از زبان فارسی.

## ساختار

هر کامپوننت در پوشه خودش شامل دو فایل است:

- `ComponentName.jsx` - منطق کامپوننت
- `ComponentName.scss` - استایل کامپوننت

مثال:

components/
├── btn/
│ ├── Btn.jsx
│ └── Btn.scss
├── input/
│ ├── Input.jsx
│ └── Input.scss
└── ...


## فایل‌های سراسری

در پوشه `components` دو فایل وجود دارد که اکثر کامپوننت‌ها به آنها وابسته هستند:

- `_colors.scss` - متغیرهای رنگی که توی کد های دیگه استفاده شدن
- `theme.jsx` - مدیریت رنگ تم سراسری

حدود ۹۰٪ کامپوننت‌ها به این دو فایل وابسته هستند.
